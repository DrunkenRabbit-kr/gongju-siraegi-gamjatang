# 공주시래기감자탕 가맹 모집 홈페이지

GitHub Pages에 바로 올릴 수 있는 정적 홈페이지입니다. `index.html`을 중심으로 `styles.css`, `script.js`, `assets/`만 사용합니다.

## 구성

- 이미지 중심 히어로: 손님으로 붐비는 노포 감자탕집 콘셉트 이미지
- 브랜드 섹션: 시래기와 뼈 국물 중심의 실제 메뉴 특성을 반영
- 메뉴 섹션: 시래기감자탕 / 뼈해장국 / 뼈찜
- 가맹 시스템, 적합한 파트너, 상담부터 오픈까지의 흐름
- 모바일 반응형 레이아웃
- 가맹 상담 입력 폼

## 상담 폼 연결

이 사이트는 GitHub Pages의 정적 호스팅 구조라서 별도 서버 없이 외부 폼 수신 endpoint로 상담 신청을 전송합니다.

- 수신처: `fcdesign000@gmail.com`
- 전송 항목: 이름, 연락처, 희망 지역, 창업 시기, 남기고 싶은 이야기
- 브라우저 `localStorage`에는 신청 내용을 저장하지 않습니다.
- 현재 연결 방식은 FormSubmit AJAX endpoint입니다.
- FormSubmit을 처음 사용하는 경우 첫 신청 후 수신 이메일로 온 확인 링크를 눌러야 메일 수신이 활성화됩니다.
- 수신 주소를 바꾸려면 `index.html`의 `data-form-endpoint`를 변경하세요.

전송 주소가 없거나 전송에 실패하면 신청이 접수된 것으로 표시하지 않고, 입력 내용도 초기화하지 않습니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소 루트에 업로드합니다.
3. `Settings → Pages → Deploy from a branch → main / root`를 선택합니다.
4. 발급된 Pages 주소에서 모바일과 상담 폼을 확인합니다.

## 사실성 메모

현재 파일에는 매출·수익 숫자나 검증되지 않은 가맹점 수를 넣지 않았습니다. 상권·운영 조건에 따라 실제 수익은 달라지므로, 운영 조건과 지원 범위가 확정되면 상담 이후 공개 가능한 사실만 추가하는 것을 권장합니다.
