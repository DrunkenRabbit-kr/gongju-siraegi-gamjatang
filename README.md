# 공주시래기감자탕 가맹 모집 홈페이지

GitHub Pages에 바로 올릴 수 있는 정적 홈페이지입니다. `index.html`을 중심으로 `styles.css`, `script.js`, `assets/`만 사용합니다.

## 구성

- 이미지 중심 히어로: 손님으로 붐비는 노포 감자탕집 콘셉트 이미지
- 브랜드 섹션: 시래기와 뼈 국물 중심의 실제 메뉴 특성을 반영
- 메뉴 섹션: 시래기감자탕 / 뼈해장국 / 뼈찜
- 가맹 시스템, 적합한 파트너, 상담부터 오픈까지의 흐름
- 모바일 반응형 레이아웃
- 가맹 상담 입력 폼

## 상담 폼 연결

GitHub Pages는 서버가 없는 정적 호스팅이므로 현재 폼은 신청자 브라우저의 `localStorage`에만 임시 저장합니다. 따라서 지금 상태에서는 관리자가 확인할 수 있는 별도 장소가 없습니다. 실제 접수를 받으려면 `script.js`의 HTML 폼에 있는 `data-form-endpoint`에 Formspree, Google Apps Script Web App 등 실제 POST 주소를 넣으세요.

```html
<form ... data-form-endpoint="https://formspree.io/f/발급받은-ID">
```

실제 본사 연락처와 개인정보처리방침 URL이 정해지면 푸터 및 상담 안내 문구에 연결하면 됩니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소 루트에 업로드합니다.
3. `Settings → Pages → Deploy from a branch → main / root`를 선택합니다.
4. 발급된 Pages 주소에서 모바일과 상담 폼을 확인합니다.

## 사실성 메모

현재 파일에는 매출·수익 숫자나 검증되지 않은 가맹점 수를 넣지 않았습니다. 상권·운영 조건에 따라 실제 수익은 달라지므로, 운영 조건과 지원 범위가 확정되면 상담 이후 공개 가능한 사실만 추가하는 것을 권장합니다.

## 확인한 매장 정보

메뉴와 영업 정보는 [네이버 업체 페이지](https://naver.me/G8s4pJcs) 확인 기준으로 정리했습니다. 페이지에서 확인되는 대표 메뉴는 시래기감자탕, 뼈해장국, 뼈찜이며, 영업 정보는 24시간·연중무휴로 표시되어 있습니다. 가맹 조건·지원 범위·수익 정보는 확인 전 임의로 확정하지 않았습니다.
